# 坦克大战（Tank Battle）

经典 Battle City 风格的单机网页小游戏。纯 HTML5 + Canvas 实现，零依赖，浏览器打开即玩。

## 玩法

1. 用浏览器打开 `index.html`（双击即可，无需服务器）。
2. 操控黄色坦克，消灭每一关的全部 **6 个敌人**。

| 按键 | 操作 |
|------|------|
| W / ↑ | 上移 |
| S / ↓ | 下移 |
| A / ← | 左移 |
| D / → | 右移 |
| 空格 | 开火 |
| Enter | 关卡完成 / 游戏结束时确认 |

## 规则

- **砖墙**：可被子弹摧毁；**钢墙**：不可摧毁。
- 保护地图底部的**老鹰（基地）**——它被击中即告失败。
- 你有 3 条生命，被击中后短暂无敌并重生。
- 消灭全部敌人进入下一关，共 2 关。
